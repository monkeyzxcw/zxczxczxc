# Каталог предметов

`item-catalog.json` подготовлен из `items.json` и `names-ru.json`, находившихся в архиве Gorn TLI 0.6.0, который пользователь предоставил для анализа. Исходный `package.json` архива указывает MIT для пакета приложения. В каталоге Nexus после нормализации: 1 935 исходных записей, 1 933 уникальных ID (`ConfigBaseId`), 1 932 уникальных ID со ссылкой на иконку. Дубликаты ID объединяются при загрузке.

Иконки не включены бинарными файлами в релиз. Nexus загружает их по требованию из `cdn.tlidb.com`, проверяет тип/размер ответа и хранит кэш локально. Наличие MIT в package metadata исходного приложения само по себе не подтверждает отдельные права на игровые изображения или CDN-контент; перед публичным распространением иконок/каталога требуется проверить условия соответствующих правообладателей и источника данных.

В каталог не включены цены, пользовательские данные, токены доступа или код удалённых сервисов. Цены получаются отдельно из игрового лога/сезонного feed и кэшируются на компьютере пользователя.
