# TLI Nexus 1.1.0 — Character, Market & Farming Intelligence

## Новое

- **Профили персонажей:** несколько локальных профилей, герой, специализация, уровень, сезон, заметки, переключение активного профиля; имя и сезон можно подставить из обнаруженной игровой сессии. Билды привязываются к профилям.
- **Лаборатория билдов:** сохраняется указанная инвестиция в FE; сравнение показывает различия введённых характеристик, отдельных строк экипировки, навыков, талантов и вложений. Сравнение не выдаёт себя за DPS-симулятор.
- **Аналитика фарма:** медиана FE/ч, среднее, P25–P75, стандартное отклонение и коэффициент вариации; стратегии ранжируются только при наличии минимум трёх валидных сессий. Незавершённая автоматическая сессия не искажает статистику.
- **История цен:** локальные точки цен по предметам, сезон и источник; запись при изменении от 2% или ежедневном снимке; срок хранения до 120 дней. График показывает минимум, максимум, последнюю цену и изменение.
- **Оповещения целевой цены:** для предметов в списке наблюдения можно задать цену в FE; Nexus уведомляет при достижении или падении ниже цели. Повторное уведомление не спамит, пока цена остаётся ниже цели; сигнал появляется снова после выхода цены выше порога и нового пересечения.
- **Резервные копии:** экспорт/импорт включает пользовательскую историю цен вместе с профилями, билдами, тактиками, настройками и сессиями. При импорте точки истории объединяются без дубликатов.
- **Совместимость:** исходный запуск устанавливает dev-зависимости Electron через `npm install --include=dev`, а не пропускает Electron. Идентификаторы форм браузера имеют fallback, если `crypto.randomUUID` недоступен.

## Сохранено из 1.0.1

- Исправление кнопки булавки и нативного `alwaysOnTop`, отдельный режим сквозного клика, горячие клавиши `Ctrl+Shift+P` и `Ctrl+Shift+M`.
- Live-парсер UE_game.log, подсчёт лута по BagMgr inventory delta, FE и оценка предметов, HUD и звуковые уведомления.

## Ограничения

- Полный автоматический импорт всех аффиксов/характеристик/талантов из лога пока не реализован. Профиль и сборка допускают ручное заполнение.
- Анализ персонажа — проверка правил, заполненности и личных целей, не точный симулятор DPS.
- Цены — ориентир по бирже/агрегату, а не гарантированная цена сделки. История цен накапливается на этом компьютере и включается в JSON-бэкап.
- Мета-тактики и руководство по боссам пока являются личной базой заметок; автоматическое знание всех текущих механик не заявляется.

## Проверки

`npm run release:check`: синтаксическая проверка, unit-тесты цен, профилей, сравнения билдов, статистики фарма, IPC и релизной конфигурации. Тест реального игрового лога пропускается без `TLI_REAL_LOG`. Финальный запуск и проверка NSIS/portable выполняются на Windows x64.

## Исправление сборки Windows

- `build.win.target` использует допустимый для electron-builder 26 формат массива строк (`nsis`, `portable`), а не объекты с `target`/`arch`.
- Разные имена установщика и portable EXE настроены через `build.nsis.artifactName` и `build.portable.artifactName`.
