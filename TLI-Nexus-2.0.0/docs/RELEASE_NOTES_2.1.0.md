# TLI Nexus 2.1.0 — Интеллект экипировки

## Новое
- Анализ только явно наблюдаемых объектов экипировки из CharacterIntel.explicitEquipment.
- Приоритеты характеристик отдельно для профиля и каждой сборки: точный ключ, подпись, вес 1–5, higher/lower/presence.
- Покрытие обнаруженных полей, слабые места в доступных данных и рекомендации по пользовательским правилам.
- Сравнение двух предметов по точным ключам и совместимым числовым значениям; неоднозначные, отсутствующие и несовместимые значения не получают победителя.

## Ограничения достоверности
- Не генерируются игровые характеристики, значения роллов, диапазоны, DPS или универсальная оценка предмета.
- Процент — покрытие пользовательских приоритетов, а не качество предмета.
- «Не обнаружено» не означает, что характеристики на предмете нет.
- Исторические наблюдения не доказывают полный и актуальный список надетых вещей. PutOn/PutOff и снимки сумки/склада не объявляются экипировкой.

## Проверка
- Добавлены unit-тесты правил, покрытия, сравнения значений и неоднозначных данных.
- Полный release:check, запуск Electron, проверка в игре и Windows EXE требуют проверки на Windows с Node.js 22.13+.
