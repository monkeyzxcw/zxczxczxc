# TLI Nexus 1.2.1 — click-through recovery hotfix

## Исправления

- `Ctrl+Shift+M` остаётся переключателем click-through.
- `Ctrl+Alt+M` теперь работает как принудительное выключение click-through и не включает режим повторно при случайном втором нажатии. Обе комбинации регистрируются даже при выключенных обычных горячих клавишах.
- Добавлена аварийная кнопка в верхней панели Dashboard. Она видна только при включённом click-through и напрямую вызывает `setIgnoreMouseEvents(false)` через main-process настройки.
- Главное окно получает обновления настроек от системного трея и горячих клавиш, поэтому аварийная кнопка и настройки не показывают устаревшее состояние.
- Переключение click-through из HUD использует IPC request/response вместо fire-and-forget сообщения.
- Подчищены дублирующие записи выбранного log path и разделитель в контекстном меню трея.

## Сохранено

- Наблюдатель надевания/снятия по подтверждённым BagMgr delta внутри `PutOn` / `PutOff`.
- Профили персонажей, экономика, история цен, аналитика стабильности фарма и лаборатория билдов из 1.2.0.

## Ограничения

- Сам HUD не может принять клик, пока включён click-through — это смысл режима `setIgnoreMouseEvents(true)`. Для выхода используется аварийная комбинация, трей или Dashboard.
- Извлечение экипировки остаётся частичным: начальные надетые предметы, соответствие слотам и аффиксы не угадываются.
