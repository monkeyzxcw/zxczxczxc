# TLI Nexus 1.2.0 — Click-through recovery + equipment observer

## Исправление сквозного клика

- `Ctrl+Shift+M` и альтернативная комбинация `Ctrl+Alt+M` теперь зарегистрированы как аварийные глобальные горячие клавиши и не отключаются вместе с обычными горячими клавишами.
- В контекстное меню системного трея добавлен переключатель «Сквозной клик». Его можно использовать, когда HUD игнорирует мышь.
- Подсказка кнопки и статус HUD объясняют, как отключить режим; сам HUD не может обрабатывать мышь, пока `setIgnoreMouseEvents(true)` включён.

## Наблюдатель экипировки

- `GameLogParser` распознаёт `PutOn` и `PutOff` как отдельные типы транзакций.
- Предмет попадает в частичный список экипировки только при подтверждённом BagMgr inventory delta: отрицательная delta внутри `PutOn` считается надеванием, положительная внутри `PutOff` — снятием.
- Трекинг переживает повторное чтение текущего лога через экспортируемое состояние парсера.
- На странице «Персонажи» отображается список подтверждённых предметов; частичный снимок можно сохранить в активный профиль.
- Nexus не придумывает слот, аффиксы, роллы, качество или уровень: они не подтверждаются текущими разобранными событиями.

## Проверки

- Добавлены тесты на аварийные горячие клавиши при `hotkeysEnabled=false`, переключение экипировки через PutOn/PutOff и игнорирование обычных переносов предмета.
- Тест реального UE_game.log пропускается без `TLI_REAL_LOG`. На Windows нужна пользовательская проверка снятия/надевания реального предмета.
