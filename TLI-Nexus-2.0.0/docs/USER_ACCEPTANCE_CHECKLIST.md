# TLI Nexus 1.3.0 — чек-лист пользовательской проверки

Отмечай пункты по мере проверки. Для каждого замечания сохрани скриншот и, если проблема касается чтения лога, последние строки раскрытой диагностики. Не публикуй полный игровой лог: в нём могут быть идентификаторы сессии и другие личные данные.

# TLI Nexus 1.2.1 — чек-лист пользовательской проверки

## A. Первый запуск и подключение

- [ ] Распаковать архив в новую папку.
- [ ] Установить Node.js 22.13+.
- [ ] Запустить `start-desktop.bat`; при первом старте дождаться установки Electron runtime. Если собран NSIS-установщик — дополнительно проверить запуск из меню «Пуск» и с рабочего стола.
- [ ] (Опционально, Windows x64) Запустить `build-installer.bat` и проверить создание NSIS-установщика и portable EXE в папке `release`.
- [ ] Убедиться, что запускаются главное окно и HUD.
- [ ] Оставить ETor и Gorn закрытыми: для Nexus они не нужны.
- [ ] Запустить Torchlight: Infinite (`torchlight_infinite.exe`).
- [ ] В игре включить `ESC → Другое → Enable Log`, затем повторно войти персонажем.
- [ ] Убедиться, что Nexus определил процесс, персонажа и область.
- [ ] В настройках проверить автопоиск `UE_game.log`.
- [ ] Проверить ручной выбор `UE_game.log`, затем вернуть автоматический режим.
- [ ] Закрыть/открыть главное окно: HUD и игровая сессия должны продолжать работать.

## B. Дроп и FE

- [ ] Подобрать обычный предмет: он появляется в списке последних находок.
- [ ] Подобрать несколько одинаковых предметов: они объединяются по ID, количество складывается.
- [ ] Подобрать FE: счётчик FE за сессию увеличивается на фактическое количество.
- [ ] Подобрать предмет с известной ценой: появляется оценка в FE.
- [ ] Подобрать предмет без цены: он отображается, но не увеличивает оценённую стоимость.
- [ ] Проверить, что привязанные предметы не включаются в продаваемую стоимость.
- [ ] Проверить, что перезапуск игры начинает новую сессию, а исторический скан не засчитывается как новый дроп.
- [ ] Открыть диагностику и убедиться, что счётчики GameLog/BagMgr изменяются при событиях инвентаря.

## C. Ценные находки и звук

- [ ] В настройках включить уведомления.
- [ ] Установить тестовый низкий порог, например 1 FE.
- [ ] Нажать «Проверить звук» или кнопку звука в HUD для разрешения воспроизведения.
- [ ] Подобрать предмет с оценкой выше порога: появляется анимированная плашка с названием, количеством и стоимостью.
- [ ] Убедиться, что звук воспроизводится один раз на событие.
- [ ] Изменить порог, выключить звук и проверить, что визуальные и звуковые уведомления регулируются отдельно.
- [ ] Вернуть желаемый порог (по умолчанию 20 FE).

## D. HUD и управление

- [ ] Переключить компактный/расширенный режим.
- [ ] Переместить HUD мышью; положение должно сохраниться после перезапуска.
- [ ] Изменить прозрачность и масштаб.
- [ ] Проверить «Поверх всех окон».
- [ ] Включить сквозной клик и убедиться, что клики проходят в игру.
- [ ] Выключить сквозной клик горячей клавишей `Ctrl+Shift+M` или через меню значка Nexus в системном трее.
- [ ] Проверить `Ctrl+Shift+O` (показать/скрыть HUD).
- [ ] Проверить `Ctrl+Shift+N` (открыть главное окно).
- [ ] Убедиться, что HUD не закрывает важные элементы интерфейса игры; подобрать удобное положение.

## E. База предметов и рынок

- [ ] Открыть «База предметов» — список должен заполниться.
- [ ] Найти предмет по русскому названию.
- [ ] Найти предмет по ID.
- [ ] Проверить загрузку иконки при доступном интернете.
- [ ] Отключить интернет: приложение не должно падать; уже кэшированные иконки должны остаться доступны.
- [ ] Открыть в игре поиск цены предмета и проверить, записалась ли цена из ответа биржи.
- [ ] Проверить список наблюдения, изменение целевой цены и удаление строки.
- [ ] Проверить калькулятор сделки с разными ценами, количеством и комиссией.
- [ ] Сверить примерную цену с внутриигровой биржей вручную.

## F. Билды и анализ персонажа

- [ ] Создать билд и заполнить героя, уровень, сезон, навык и тип урона.
- [ ] Добавить экипировку, навыки поддержки, таланты и заметки.
- [ ] Сохранить билд, закрыть и снова открыть программу: билд должен сохраниться.
- [ ] Экспортировать код `NEXUS1`, затем импортировать его как новую сборку.
- [ ] Сравнить две сборки: поля и числовые отличия отображаются корректно.
- [ ] Внести фактические характеристики персонажа и личные цели.
- [ ] Запустить анализ: ниже заданных целей появляются предупреждения.
- [ ] Проверить конверсию урона, если в настройках билда включено ожидание 100%.
- [ ] Убедиться, что отчёт не показывает выдуманный DPS и явно говорит, что это rule-check.

## G. Фарм и тактики

- [ ] Провести игровую сессию, убедиться, что она появилась в истории автоматически.
- [ ] Ввести расходы в FE и название стратегии.
- [ ] Сохранить расходы: чистая прибыль и FE/час пересчитываются.
- [ ] Убедиться, что сохранение заметки не сбрасывает более свежую автоматическую статистику сессии.
- [ ] Создать тактическую заметку с категорией и контекстом сезона/патча.
- [ ] Найти её поиском, отредактировать и удалить.

## H. Резервная копия и устойчивость

- [ ] Открыть папку данных через настройки и убедиться, что локальная база Nexus там создаётся.
- [ ] Экспортировать JSON-резервную копию.
- [ ] Изменить/добавить тестовую заметку и импортировать копию.
- [ ] Убедиться, что данные восстановились.
- [ ] Закрыть Nexus через трей и запустить снова.
- [ ] Проверить, что настройки, сборки, тактики, история и локальные кэши не потерялись.
- [ ] Проверить, что Nexus работает при закрытом ETor и Gorn.

## I. Известные ограничения, не считать дефектом

- [ ] Не ожидать автоматического считывания всего листа характеристик персонажа из обычного UE-лога: недостающие значения вносить вручную.
- [ ] Не ожидать точного симулятора DPS/боссов в этой версии.
- [ ] Не ожидать готовой автоматической мета-тактики: личные заметки и статистика фарма работают отдельно.
- [ ] Не ожидать автоматического обновления самой программы: обновление версии пока устанавливается новым архивом.

### Важное условие приёмки

Автоматические проверки используют синтетические тестовые протоколы, а не твой живой лог. Для завершения приёмки пришли диагностический снимок раздела Character Intelligence после сканирования реального `UE_game.log` (полный файл отправлять не обязательно). По нему можно безопасно уточнить реальные aliases и формы данных конкретной версии клиента.
