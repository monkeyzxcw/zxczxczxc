# TLI Nexus 1.4.0 — Character Intelligence 2.0

## Что добавлено

- Новый `core/characterIntel.js` — единый парсер сведений о персонаже с источником и доказательством для каждого поля.
- Историческое восстановление из последних 32 MiB `UE_game.log` и повторное сканирование без сброса/повторного учёта исторического лута.
- Идентификация через `GetPlayerData`: Player ID, имя, Season ID, Hero ID/имя, уровень, ID/имя специализации и сервер, если они присутствуют.
- Извлечение только явно известных числовых alias характеристик с сохранением сырого имени поля, пути, action, kind и timestamp.
- Извлечение явных ID навыков/талантов; ID не преобразуются в названия без разрешённого и актуального каталога.
- Снимки `ResetItemsLayout` / `GetWareHousePage` отображаются как сумка/хранилище, а не как надетая экипировка.
- Схема неизвестных интересующих полей и счётчики протокольных действий доступны в диагностике.
- Наблюдаемые показатели, навыки, таланты и снимки инвентаря можно переносить в черновик билда, сохраняя provenance.
- `observedStats` сохраняются в билде и участвуют в сравнении; источники и timestamp не теряются.
- Скан и данные Character Intelligence сохраняются в соответствующем профиле; старые профили и NEXUS1 коды остаются совместимыми.
- Добавлены синтетические тесты парсера и интеграционная проверка исторического восстановления из синтетического UE-лога.

## Что по-прежнему не утверждается

- `ResetItemsLayout` / `GetWareHousePage` не являются надетой экипировкой.
- `PutOn` / `PutOff` дают частичный след BagMgr. `PageId` / `SlotId` не трактуются как слоты экипировки.
- Слоты, аффиксы, роллы, качество и полные характеристики предметов не угадываются.
- ID навыков/талантов не получают вымышленных названий.
- Полный игровой DPS-симулятор и автоматическое восстановление всех талантов/аффиксов не входят в этот релиз.
- Для оценки полноты на конкретном клиенте нужен пользовательский настоящий `UE_game.log`; автоматический тест с `TLI_REAL_LOG` пропускается, если этот файл не задан.
