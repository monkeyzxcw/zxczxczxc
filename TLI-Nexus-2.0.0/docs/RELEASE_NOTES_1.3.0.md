# TLI Nexus 1.3.0 — Character, Market & Farming Intelligence

## Профили персонажей

- Добавлены отдельные профили персонажей с героем, специализацией, уровнем, сезоном и заметками.
- Поддерживается автоматический выбор профиля по текущему имени игрока и SeasonId.
- В профиль сохраняются последняя область, сезон, время обнаружения, executable и последние частичные снимки экипировки.
- Автоматические фарм-сессии привязываются к найденному профилю. В настройках можно выключить автопереключение профиля.

## История цен и уведомления рынка

- Локальная история цен сохраняет сезон, источник, число наблюдений и временную метку.
- Хранение до 120 дней и максимум 120 точек на предмет; запись при изменении от 2% или по суточному интервалу.
- График поддерживает 7/30/90/120 дней, текущий сезон и все сезоны.
- У целевой цены есть состояние пересечения порога. Уведомление генерируется при первом падении к цене цели или ниже и повторно вооружается после роста выше цели.
- Состояние наблюдений синхронизируется в локальную базу, чтобы устаревший снимок renderer не стирал его.

## Аналитика фарма

- Считаются чистая прибыль, FE/час, медиана, среднее, P25–P75, стандартное отклонение, MAD, коэффициент вариации, доля прибыльных сессий, минимум/максимум.
- Сравнение стратегий и выбор лидера требуют минимум трёх завершённых сессий.
- Добавлен фильтр истории и сводки по профилю персонажа.
- Активные live-сессии не участвуют в рейтинге до завершения.

## Лаборатория билдов

- Билды привязываются к профилям персонажей.
- Сравнение включает характеристики, именованные слоты экипировки, навыки/поддержки, ключевые таланты и вложенные FE.
- Для строк `Слот: Предмет` сравнение идёт по названию слота, поэтому порядок записей не создаёт ложных различий.
- Наблюдаемые предметы из equipment tracker можно перенести в черновик билда; имена и ID добавляются без неподтверждённого назначения слотов.

## Частичное восстановление экипировки

- `EquipmentTracker` ведёт состояние предметов по подтверждённым BagMgr inventory delta внутри `PutOn` и `PutOff`.
- Поддерживается восстановление состояния tracker при пересборке GameLogParser.
- В профиле сохраняются частичные снимки и до 20 предыдущих состояний.
- Не определяются автоматически начальная экипировка, точное соответствие слотов, аффиксы, значения роллов, качество или уровень предмета, если лог не передал подтверждающие поля.

## Совместимость и сохранность

- Сохранён click-through hotfix 1.2.1, включая аварийные горячие клавиши и меню трея.
- История цен входит в JSON-резервную копию и импортируется с дедупликацией.
- Renderer не может затереть более свежие profile/equipment/price-watch метаданные или profileId автоматической сессии.

## Проверки

- `npm run check`: синтаксис основного Electron, UI и core модулей.
- `npm test`: unit/regression тесты профилей, целевых цен, сезонной истории, стабильности фарма, named-slot build compare и PutOn/PutOff.
- `npm run build:desktop`: проверка конфигурации Electron, ресурсов и Windows targets.
- Реальный `UE_game.log` и Windows NSIS/portable build должны быть проверены на Windows пользователем; тест настоящего лога пропускается без `TLI_REAL_LOG`.

## Надёжность после приёмочных проверок

- При включении уведомлений или изменении настроек оповещений рынок проверяется немедленно по уже известным ценам; не требуется ждать следующего сетевого обновления.
- Устаревшее сохранение Dashboard больше не может отбросить более длинную историю снимков экипировки, которую обновил главный процесс.
- В профиле отображаются последние подтверждённые переходы `PutOn` / `PutOff` и несколько предыдущих сохранённых снимков.
- Автовыбор профиля повторно выполняется и после загрузки локального хранилища, и после восстановления состояния активной игры.
