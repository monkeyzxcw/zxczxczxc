# TLI Nexus 2.2.0 — Игровые ресурсы и данные аффиксов

## Ключевые изменения
- Локальный импортёр FModel/Unreal JSON: DataTable, RowMap, определения предметов и аффиксов, пути источников и структура ресурсов.
- Сопоставление точных ID аффиксов и предметов из UE_game с импортированными строками.
- Расширенное извлечение сырых item/affix полей, тир-сигналов, уровня, качества, редкости, усиления и слота.
- UI импорта и статуса базы в Настройках.
- Проверки и документация по извлечению игровых ресурсов.

## Статус базы в этом релизе
В архиве пользователя не найдено самих DataTable с аффиксами/роллами. Найдены типы схемы из DefaultGame и ссылки на UI/Lua ресурсы в FModel-логе. Поэтому индекс после импорта архива должен показывать ноль определений аффиксов. Это намеренно: ни один UI Blueprint или ID enum не преобразуется в выдуманный стат.

## Обновление
Перед импортом выбери папку FModel JSON-экспорта в Настройки → Игровая база: предметы и аффиксы. Индекс хранится локально отдельно от профилей и логов. Для обновлённого каталога просто выполни импорт снова.

## Проверка
- Добавлены unit-тесты парсера item/affix evidence и DataTable scanner.
- Release verifier проверяет новые модули и документы.
- Полный `npm run release:check`, реальная проверка на UE_game.log и сборка Windows EXE требуют отдельного запуска на Windows с Node.js 22.13+.


## Дополнительная схема 2.2.0

- Enum-таблицы `AffixAttrType`, `GameCharAttribute`, `GameCharField`, `GameEquipSlot`, редкости и качества хранятся отдельно от аффиксных роллов.
- При анализе предмета тип характеристики может быть разрешён по точному AttrType ID даже без найденной строки аффикса. Это не считается совпадением полного определения аффикса.
- Таблицы слотов, редкости и качества имеют раздельные пространства ID, чтобы совпадающие числа разных enum не смешивались.

- Импортируются отдельные enum-таблицы AttrType, полей/атрибутов персонажа, слотов, редкости и качества. Их числовые ID разрешаются только в собственном типе таблицы.
- Если доступна только enum-запись AttrType, Nexus показывает название характеристики отдельно, не выдавая это за найденное полное определение аффикса.


## Внешняя база аффиксов TLIDB
- Добавлена загрузка таблиц с 38 публичных страниц TLIDB по нажатию пользователя.
- Сохраняются базовые аффиксы, коррозия, крафтовые роллы, диапазоны, тиры, уровни предмета, вес, категория и URL-источник.
- Добавлен локальный поиск по названию свойства и группе экипировки.
- Внешний справочник хранится отдельно на компьютере пользователя; он не включён в установщик или резервные копии.
- Внутренние игровые AffixId / AttrType не выводятся из названий и остаются неизвестными.
- Версия сезона/патча TLIDB не подтверждается самими таблицами. Совместимость с SS14 отмечается как непроверенная.

### Внешняя база — ограничения
TLIDB является фанатским справочником. Интеграция использует страницы как справочный источник и не объявляет её официальным API или гарантированно актуальной таблицей SS14. Для точного сопоставления ID продолжает использоваться отдельный импорт FModel/Unreal JSON.
