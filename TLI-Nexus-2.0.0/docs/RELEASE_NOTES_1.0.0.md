# TLI Nexus 1.0.0 — Release notes

## Что входит

- Сохранён рабочий live-парсер 0.4.3: UE log tail, GameLog inventory-delta, персонаж, область, сгруппированный лут и оценка FE.
- Отдельное Electron-окно Dashboard и компактный/расширенный HUD.
- Настройки HUD: прозрачность, масштаб, положение, always-on-top, click-through, системные горячие клавиши.
- Уведомления о ценном дропе, собственная мини-анимация и синтезированный звук с настраиваемым порогом.
- База предметов из пользовательского референсного архива: 1 935 исходных записей, 1 933 уникальных ID после дедупликации; иконки загружаются по требованию и кэшируются.
- Сборки: локальное создание/редактирование, сохранение, сравнение характеристик и обмен через формат NEXUS1.
- Анализатор заполненных характеристик, личных целей и простых противоречий.
- Автоматическая история игровых сессий, ручные расходы и FE/час.
- Личная база тактик/заметок, список наблюдения за ценами и калькулятор сделки.
- Импорт/экспорт локальной резервной копии JSON.

## Проверки разработки

- Синтаксическая проверка всех основных JS-модулей.
- Набор автоматических тестов `node --test test/*.test.mjs`.
- Тесты read-only tailer, парсера UE/GameLog, инвентарных delta, цены/FE и суммирования лута.
- Тесты сохранения билдов, обменного кода, анализатора, каталога, уведомлений и защиты авто-сессии от stale renderer writes.
- Ручная проверка на Windows с живой игрой остаётся задачей пользовательской приёмки; тест с реальным `UE_game.log` пропускается без `TLI_REAL_LOG`.

## Не входит в 1.0.0

- Полный точный DPS-симулятор игры.
- Автоматическое извлечение полного листа статов, дерева талантов и всех аффиксов из игры.
- Автоматический импорт сторонних build-code форматов.
- Автоматическая мета-база тактик/боссов и гарантированно актуальные рекомендации без сезонного обновления источников.
- Подписанный установщик MSI/EXE и автоматический updater.
