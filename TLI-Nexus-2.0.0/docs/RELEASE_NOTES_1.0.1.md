# TLI Nexus 1.0.1 — HUD pin fix

## Исправления

- Добавлена отдельная кнопка закрепления/открепления HUD поверх окон.
- Состояние кнопки визуально отражает нативное состояние always-on-top.
- Переключение выполняется через подтверждаемый IPC-вызов `app:set-always-on-top`.
- При откреплении вызывается `BrowserWindow.setAlwaysOnTop(false)` без уровня `screen-saver`, чтобы снять нативный флаг поверх всех окон.
- Кнопка сквозного клика остаётся отдельной настройкой и больше не смешивается с закреплением.
- В нижней строке HUD отображается `PINNED` или `UNPINNED`.

## Проверка

- Автоматические тесты проверяют доступность кнопки, IPC-маршрут и снятие нативного topmost-флага.
- Финальная проверка поверх Torchlight: Infinite выполняется на Windows с пользовательской приёмкой.

- Добавлена горячая клавиша `Ctrl + Shift + P`; пункт трея «Поверх всех окон» синхронизируется с состоянием кнопки.
