# TLI Nexus 2.4.0 — полный анализ билда

## Основная возможность

В раздел «Анализ персонажа» добавлен единый evidence-first аудит сохранённой сборки. Он объединяет данные сохранённого билда, Character Intelligence из UE_game.log, явные объекты экипировки, локальные FModel DataTable и состояние локального кэша TLIDB.

## Что показывает отчёт

- Текущие характеристики, их источник, личные цели и точный разрыв до цели.
- Несовпадения между сохранёнными значениями билда и последним игровым снимком.
- Сверку навыков/поддержек и талантов по точным ID; свободный текст без ID не считается подтверждённым совпадением.
- Предметы и аффиксы из явной структуры экипировки. При точном совпадении ItemId/AffixId с FModel DataTable показываются сведения каталога, AttrType, тир и Min/Max.
- Положение числового ролла внутри точного диапазона, если значение однозначно распознано и единицы измерения совпадают.
- Упорядоченные действия для закрытия личных целевых разрывов, проверки отсутствующих ID и сравнения низких роллов.

## Ограничения и точность

- Покрытие данных не является силой персонажа или рейтингом билда.
- Полный комплект экипировки не предполагается: анализируются только явные объекты CharacterIntel. PutOn/PutOff и снимок инвентаря остаются частичными источниками.
- TLIDB — фанатский справочник. Внутренние AffixId/AttrType и текущий сезон/патч по публичной таблице не выводятся; текстовые аффиксы не склеиваются с игровыми ID по похожему названию.
- Таблицы эффектов навыков, связей поддержек и талантов пока не подтверждены. Поэтому Nexus может проверить наблюдаемые ID, но не утверждает, что конкретная поддержка или талант даёт конкретный множитель.
- DPS, EHP и мета-рейтинг не симулируются без проверенных формул игры и версии патча. Nexus объясняет доказуемые пробелы и расхождения, а не подменяет их выдуманными числами.

## Проверки

Добавлены unit-тесты точной сверки навыков/талантов, целевых разрывов, FModel-диапазона аффикса, частичной экипировки, фокуса урона и устаревшего снимка.
