# TLI Nexus 2.3.0

## Исправления стабильности
- Временная ошибка определения процесса Torchlight больше не должна сразу останавливать tailer и обнулять сессию: при подключённом логе используется grace period 2 минуты.
- Переподключение или ротация UE-лога сохраняет накопленные предметы, FE и длительность сессии; на границе потока пересоздаются только парсеры.

## Экипировка и таланты
- Индекс локальных игровых ресурсов теперь извлекает определения узлов талантов из DataTable.
- Добавлено сопоставление названий талантов, предметов, слотов и аффиксов по точным ID и localization keys.
- Неизвестные ID не превращаются в выдуманные названия или характеристики.

## Интерфейс
- Основная навигация сокращена до пяти разделов; вспомогательные страницы скрыты в раскрываемом блоке.
- Сырые JSON-поля, ручная сетка характеристик и подробная диагностика скрыты в расширенных настройках.
- Убраны числовые ID из основных подписей предметов; технические сведения остаются доступны отдельно.
- Увеличены размеры текста, интервалы и контраст.

## Ограничения
- Названия из игровых ресурсов появляются только при импорте подходящих DataTable и локализаций.
- Полное восстановление слотов и роллов экипировки требует реальных подтверждённых игровых полей.
- Необходима проверка на реальной Windows-сборке и в игре, включая длительный Alt+Tab.
