# TLI Nexus 2.3.0 — автоматическая синхронизация TLIDB

## Что изменилось

- TLIDB автоматически загружается при первом запуске или когда локальный кэш старше выбранного интервала.
- По умолчанию включено обновление раз в 24 часа. Интервал можно выбрать: 6, 12, 24, 48 часов или 7 дней.
- Синхронизация выполняется в основном процессе Electron и не требует открытой страницы настроек.
- Ручное обновление по кнопке сохранено.
- Одновременные ручная и автоматическая загрузки объединяются в одну операцию.
- Кэш записывается атомарно только после получения пригодных данных.
- Если отдельные страницы TLIDB временно недоступны или сервер ограничивает запросы, предыдущие данные этих страниц остаются в кэше. Остальные успешно полученные страницы обновляются.
- После сетевой ошибки приложение повторяет автоматическую попытку примерно через час.
- В настройках отображаются интервал, дата последней полной синхронизации, ошибки и количество сохранённых старых страниц.
- Исправлена инициализация TLIDB в интерфейсе: блок базы больше не зависит от нажатия «Импортировать игровые ресурсы».

## Ограничения источника

TLIDB остаётся фанатским справочником, а не официальным API. Автоматическая загрузка не подтверждает совместимость записей с текущим сезоном или патчем. Внутренние игровые `AffixId` и `AttrType` из публичных таблиц не угадываются. Для автоматического обновления нужен интернет и доступность `tlidb.com`.

Кэш остаётся локальным на компьютере пользователя и не включается в установщик или резервные копии.
